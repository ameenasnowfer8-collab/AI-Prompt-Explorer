##  AI Prompt Explorer

##  Project Description

AI Prompt Explorer is an interactive Large Language Model (LLM) application that demonstrates how different prompting styles can generate different types of AI responses.

The application uses the **Groq API** and **Streamlit** to provide an easy-to-use interface where users can enter a topic and explore three different prompting approaches:

- Simple Prompt
- Expert Prompt
- Q&A Prompt

The prompts are sent to the LLM, and the generated responses are displayed in the application for comparison and exploration.

---

##  Objectives

The main objectives of this project are:

1. To understand the working of Large Language Models.
2. To explore different prompting styles.
3. To understand how prompt design affects AI-generated responses.
4. To integrate the Groq API with a Python application.
5. To develop an interactive LLM application using Streamlit.

---

##  Technologies Used

- **Python**
